    13. Apéndices

    13.1. Instalación de JDK 21

    [JDK] ([Java Development Kit]) contiene el compilador [javac] y la máquina virtual [java]. Hay varias distribuciones gratuitas disponibles; usamos [Eclipse Temurin], del proyecto [Adoptium], que se puede descargar desde adoptium.net: seleccione la versión 21 (LTS) y luego el instalador para su sistema ([Windows] x64, [macOS], [Linux]).

    En [Windows], el instalador [.msi] ofrece la opción «Set JAVA_HOME variable» en la pantalla de personalización; esta opción está deshabilitada de forma predeterminada: hay que habilitarla. La variable de entorno [JAVA_HOME] indica la ubicación del [JDK]; el Maven Wrapper la usa para localizar [Java]. También se puede usar el administrador de paquetes [winget]:

    1
    winget install EclipseAdoptium.Temurin.21.JDK

    Para [macOS], use el instalador [.pkg] de la misma página, o el administrador de paquetes [Homebrew] ([brew install --cask temurin@21]). Para [Linux] ([Ubuntu], por ejemplo), basta el paquete [openjdk-21-jdk] de los repositorios de la distribución:

    1
    sudo apt install openjdk-21-jdk

    Verifique la instalación en una consola nueva ([PowerShell], símbolo del sistema o terminal):

    1
    java -version

    que debería mostrar un número de versión que comience con 21 (por ejemplo, [openjdk version "21.0.10"]). Un [JDK] más reciente (25, por ejemplo) también funciona; un [JDK] más antiguo (17, por ejemplo) produce el error [release version 21 not supported] durante la compilación.

    13.2. Maven y el Maven Wrapper

    No hay nada que instalar: la carpeta [examples] y la carpeta del caso de estudio contienen cada una el Maven Wrapper, los scripts [mvnw] ([Linux], [macOS]) y [mvnw.cmd] ([Windows]), junto con el archivo [.mvn/wrapper/maven-wrapper.properties], que especifica la versión de [Maven] que se debe usar (3.9.11). Al ejecutarse por primera vez, el script descarga esta versión de [Maven] y la almacena en el directorio personal del usuario (carpeta [.m2/wrapper]); las ejecuciones posteriores la reutilizan. [Maven], a su vez, descarga las bibliotecas del proyecto desde el repositorio Maven Central y las almacena en la carpeta [.m2/repository]. Por lo tanto, se requiere conexión a Internet durante la primera compilación.

    El Maven Wrapper requiere [Java]: usa el [JDK] especificado por la variable [JAVA_HOME] o, en su defecto, el comando [java] que se encuentre en la ruta de búsqueda ([PATH]). Para verificar que todo está en orden, compile todos los ejemplos desde la carpeta [examples]:

    1
    ./mvnw compile

    ([.\mvnw compile] en [Windows]). El comando termina con [BUILD SUCCESS].

    Si prefiere instalar [Maven] usted mismo (maven.apache.org), el comando [mvn] reemplaza a [mvnw] en todos los comandos del documento.

    13.3. Instalación de Visual Studio Code

    Descargue [Visual Studio Code] desde code.visualstudio.com. Agregue dos extensiones (vaya al menú View > Extensions y busque sus nombres):

    • [Extension Pack for Java], de Microsoft: un conjunto de extensiones que ofrece resaltado de sintaxis, autocompletado de código e informe de errores para el código [Java]; compatibilidad con proyectos [Maven] (panel Java Projects); el depurador y la compilación automática de cada archivo guardado;
    • [Spring Boot Extension Pack], de VMware (marketplace.visualstudio.com): autocompletado de propiedades para [application.properties], navegación entre beans y URL de los controladores, y el panel Spring Boot Dashboard, que enumera las aplicaciones [Spring Boot] de la carpeta abierta y permite iniciar o detener cada una con un solo clic.

    Abra la carpeta [examples] o la carpeta del caso de estudio (menú File / Open Folder); el terminal integrado (menú Terminal / New Terminal) permite ejecutar comandos [mvnw] sin salir del editor. La tecla F5, en la clase de inicio de una aplicación (la que se llama [@SpringBootApplication]), ejecuta la aplicación bajo el control del depurador.

    13.4. Instalación de MySQL con Laragon

    [Laragon] (laragon.org) instala un servidor [MySQL] (o [MariaDB]) listo para usar, junto con la herramienta de administración [HeidiSQL]. Después de la instalación:

    • el botón «Start All» inicia el servidor [MySQL] en el puerto 3306;
    • el usuario [root] no tiene contraseña: son los valores predeterminados de las propiedades [spring.datasource.*] del ejemplo 28 y del caso de estudio;
    • El botón Database abre [HeidiSQL], donde la opción File / Run a File de SQL ejecuta los scripts [dbpersons.sql] (ejemplo 28) y [dbrdvmedecins2.sql] (caso de estudio).

    En [Linux] o [macOS], instale [MySQL] o [MariaDB] con el administrador de paquetes del sistema y ejecute los scripts con el cliente de línea de comandos [mysql]. El controlador [JDBC] de [MySQL] también funciona con [MariaDB] sin ninguna configuración: [Hibernate] solo muestra la advertencia [HHH000511] al iniciar, sin consecuencias (véase el ejemplo 28).

    13.5. Instalación de curl

    [curl] viene incluido con [Windows] 10 y 11, [macOS] y la mayoría de las distribuciones de [Linux]. En [PowerShell], debe escribir [curl.exe], no [curl]: en las versiones antiguas de [PowerShell], [curl] es un alias de otro comando ([Invoke-WebRequest]), que tiene opciones distintas.
